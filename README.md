# 🤖 Local RAG Chatbot

A **fully offline Retrieval-Augmented Generation (RAG)** chatbot built with LangChain, Hugging Face models, FAISS, and Streamlit. This chatbot can answer user questions based on:
- Uploaded customer support documents (PDF, DOCX)
- Web content automatically crawled from [Angel One's Support Pages](https://www.angelone.in/support)

It uses **local embeddings and a local language model**, ensuring your data never leaves your machine.

---

##  Features

-  **Retrieval-Augmented Generation**: Answers are grounded in actual source material.
-  **Runs 100% Locally**: No API keys, no cloud calls, no internet required after setup.
-  **Semantic Search**: Powered by `sentence-transformers/all-MiniLM-L6-v2` for embeddings.
-  **Natural Language Responses**: Generated by `google/flan-t5-base`, a compact and effective open-source LLM.
-  **Interactive Web UI**: Built using Streamlit with a chatbot-style interface.
-  **Custom Knowledge Base**: Use your own PDFs, DOCXs, and website content.

---

##  How It Works

##  `app.py` — Streamlit Chatbot UI

**Purpose**:  
Provides a web-based, chatbot-style interface for interacting with your RAG model.

**Key Features**:
- Loads a local FAISS vector index
- Loads a local Hugging Face model (`flan-t5-base`)
- Accepts user input through a chatbot interface
- Maintains session state and conversation history
- Returns answers based only on the retrieved context
- Fully offline, runs in the browser via Streamlit

**UI Flow**:
- You type a question.
- It retrieves relevant chunks using semantic similarity.
- It generates a natural language answer from the local model.
- The conversation is displayed like a chatbot history.

---

##  `chunk_embed.py` — Document Chunking & Embedding

**Purpose**:  
Splits your preloaded documents into smaller chunks and embeds them using `sentence-transformers` to prepare for semantic search.

**What it does**:
- Imports `all_documents` from `data_ingestion.py`
- Splits text into overlapping chunks using `RecursiveCharacterTextSplitter`
- Generates vector embeddings for each chunk
- Saves a FAISS vector index to `./vectorstore/`

**Run this script every time** you:
- Add new documents
- Modify existing documents
- Want to refresh the knowledge base

---

##  `data_ingestion.py` — Load & Crawl Documents

**Purpose**:  
Loads all customer support files (PDF and DOCX) and crawls Angel One support pages.

**What it does**:
- Loads files from the `/docs/` directory using `PyPDFLoader` and `UnstructuredWordDocumentLoader`
- Crawls the `https://www.angelone.in/support` site using `BeautifulSoup`
- Extracts support article URLs (up to 100 pages)
- Loads content from each page using `WebBaseLoader`
- Merges local and web documents into `all_documents`

**Output**:  
The combined list of documents (`all_documents`) used in `chunk_embed.py`.

---

##  `rag_chatbot.py` — CLI Chatbot (Terminal-Based)

**Purpose**:  
Runs the same chatbot engine as `app.py`, but in a terminal-based loop instead of a web UI.

**What it does**:
- Loads the FAISS vector index
- Loads the Hugging Face LLM (`flan-t5-base`)
- Defines a custom prompt template
- Enters a loop to take user questions
- Outputs answers in the terminal

**Ideal for**:
- Testing the chatbot logic without the browser
- Running in headless/server-only environments

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/rag-chatbot.git
cd rag-chatbot
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
source venv/bin/activate         # Windows: venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Add Your Documents and Load Them

Place all PDF or DOCX documents into the `docs/` folder. These will form the knowledge base of your chatbot.
Load them with
```
python data_ingestion.py
```

### 5. Build the Vector Index

```bash
python embed_documents.py
```

This will:
- Parse your documents
- Generate embeddings
- Crawl Angel One support pages
- Save everything into `vectorstore/`

### 6. Start the Chatbot UI

```bash
streamlit run app.py
```

Open the URL shown in your terminal (usually [http://localhost:8501](http://localhost:8501)).

## 🧠 Models Used

| Component        | Model Name                        | Description                            |
|------------------|-----------------------------------|----------------------------------------|
| Embeddings       | `all-MiniLM-L6-v2` (SBERT)        | Fast and effective semantic search     |
| Language Model   | `flan-t5-base`                    | Open-source text generation model      |

All models run locally using Hugging Face’s `transformers` library. No internet required after setup.
